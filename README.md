# EGOR//OS

Статический шуточный сайт про Егора, ALT Linux и егориков. HTML, CSS и обычный JavaScript, без сборки и npm-зависимостей.

## Запуск

Откройте `dist/index.html` в браузере или запустите из каталога проекта:

```sh
node server.cjs
```

Адрес: http://127.0.0.1:4173.

## Содержимое

- `dist/` — готовый сайт, включая 13 исходных фотографий и портрет для боковых баннеров из этой подборки.
- `agents.md` — документация проекта.

- `check-spawn.cjs` — локальная браузерная проверка. Требует Chrome и Playwright из runtime Codex по пути, указанному в скрипте.

Обе кнопки запускают по 5 разных случайных фото без ограничения числа запусков. Счётчик сбрасывается при перезагрузке страницы.

Публикация на Sites и GitHub Pages отдельно не настроена.
